# 《这一百年》

挑 1926–2025 里的一年一个月，落进那时候的中国，在一座城里过三十天。
每天写一份自己要做的事的清单（上限 500 汉字），模型照那一年真实的条件演算当天发生了什么。
写不出来就点上面那三条——每天算完，模型顺手给三条明天能走的路，点一条就填进格子里，还能接着改。
三十天后结算家底，按「你赚到了几年的收入」进世界排行榜。

## 跑起来

```bash
node tools/check-engine.js          # 算账部分的检查，几秒钟，不花钱
node tools/check-years.js           # 一百张年卡的硬闸，不花钱

secret exec OPENROUTER_API_KEY -- node server.js       # 前台，127.0.0.1:8801
open http://127.0.0.1:8801
```

不带密钥也起得来：`/api/health` 回 `ai:false`，每天的演算走本地兜底，
能玩完一整局，只是正文是模板。

## 目录

| | |
|---|---|
| `data/spine-src.js` | 一百年的数字脊梁，手写。每年的货币、中位年收入、物价、四次换币 |
| `data/spine.json` | `tools/build-spine.js` 摊出来的「每年每月」，自带六条自检 |
| `data/tech-timeline.json` | 「这东西哪年才有 / 哪年就没了 / 哪几年干这个犯法」，87 条 |
| `data/years/*.json` | 一百张年卡，模型生成、硬闸过过 |
| `engine.js` | 算账：时间、货币、家底、上限、结算。纯函数，不碰网络 |
| `sim.js` | 一天怎么算：提示词、说人话的机械闸、没密钥时的本地兜底 |
| `db.js` | 存档和排行榜，用 Node 自带的 `node:sqlite`，零依赖 |
| `server.js` | HTTP。限流、静态文件、八个接口 |
| `public/` | 网页。没有打包器，三个文件 |
| `tools/` | 生成、检查、机器人、标定、截图 |

## 两个模型，分工不同

| 干什么 | 用谁 | 为什么 |
|---|---|---|
| 写年卡（一辈子一次） | `deepseek/deepseek-v4-flash` | 比出来的：写得最像人话。慢无所谓 |
| 每天的演算（一局 30 次） | `google/gemini-3.1-flash-lite` | 量出来 3.3 秒；deepseek 要 16 秒 |

换模型：`HY_MODEL=... node server.js`；年卡那边是 `tools/gen-years.js --model`。

## 分数怎么算

```
分数 =（收工那天的家底 × 那天的钱值多少 − 开局那天的家底 × 开局那天的钱值多少）
       ÷ 开局那个月的中位年收入
```

读出来就是「三十天里赚到了几年的收入」。分子分母同一种钱，所以 1935 年换法币、
1948 年换金圆券、1955 年换人民币都不影响排名——**这也是为什么这个游戏敢把舞台放在中国。**

界面上的钱用那一年真正流通的那种：银元、法币、金圆券、人民币。
1948 年 8 月你早上的余额买得起两个烧饼，下午买不起了。

## 几条容易踩的

- **推进天数一律走 `E.advanceTo(s, n)`**，不要自己改 `s.day`。
  换币那天要靠它触发；漏掉的话 1948 年 8 月会算出「赚了二十八万年的收入」。
  `settle` 会当场报错拦住这种情况。
- **现金变化由分录相加得出**，不用模型报的总数。让模型既写正文又心算总账，两边必然对不上。
- **改完 `data/tech-timeline.json` 要重跑 `node tools/check-years.js`**，
  已有的年卡可能因此变成不合格。
- 一天的上限、开局本钱、结算分母，全部按**当天那种钱**算（`incomeAtDay`），不是开局那天。
