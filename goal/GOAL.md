# 目标

一个能玩的网页游戏《这一百年》：玩家挑 1926–2025 里的任意一年、任意一个月，落进那时候的
中国过 30 天。每天写一份行动清单（上限 500 汉字），模型照当年的真实约束演算当天发生了什么，
30 天后结算家底，进两层排行榜。上线在 `https://100y.swaylab.ai`。

**2026-09-02 下午改过口径**（sway 通过 asst 回的四条），下面这份是新的。
旧版在 git 里，改了什么见 `ROUNDS.md` 第 10 轮。

# 验收标准

1. [ ] **100 张年卡是查资料写死的，每张带出处** — 怎么验证：`node tools/check-years.js` 退出码 0。
   除原有的字段与跨时代检查外，还钉死：每张卡 `sources` ≥4 条、必须覆盖 prices / money / events
   三类、至少 2 条带能打开的 URL、有 `confidence`。
   另外 `node tools/check-sources.js --sample 20` 随机抽 20 条带 URL 的出处**真的去访问**，
   打不开或页面里找不到相关内容的要报出来（允许少量失效链接，但捏造的成批出现就会露馅）。

2. [ ] **三个极端年份都能打完整 30 天并出结算** — 怎么验证：
   `node tools/bot.js --runs 1948-08,1962-05,2015-06` 三局都走满 30 天、都出结算，
   日志在 `logs/bot-*.jsonl`，**且日志的时间戳晚于最后一次引擎改动**。

3. [ ] **跨时代的胡说会被顶回去，而且稳定** — 怎么验证：
   `node tools/check-anachronism.js` **连跑三次都要 13/13**（上一版只跑一次，五次里挂过两次，
   挂的两次都是检查脚本自己用词表判语义判错了，不是游戏错）。

4. [ ] **两层排行榜立得住** — 怎么验证：
   ①**年榜**：`/api/board?year=1948` 只列这一年的局，按当年那种钱净赚多少排；
   ②**总榜**：`/api/board` 按「当年汇率换成当年美元 ÷ 当年世界 GDP × 2025 年世界 GDP」排，
   底数在 `data/world.json`，`node tools/build-world.js --check` 退出码 0；
   ③`node tools/calibrate.js --per 3` 里**认真打的中位数要高过敷衍打**（四个年代各三个种子），
   并且**每个年代的中位数都是正的**（哪个年代都得玩得下去）。
   ④**挣多少记多少，没有上限**（sway 2026-09-05 定的）——`check-engine.js` 的 2b 条钉住
   「月月做到头，二十四个月照实累加」，2c 条钉住剩下的唯一一道：数目比那一年做到头的一个月
   还高一千倍时按单位写错折回去（换币后照旧钱记账、清单里注入 `1e12` 都走这一条）。
   （旧版还有一条「最高年代不超过最低 8 倍」。年榜出现之后这条不再需要：
   年内公平由年榜保证，总榜是一个说得清的统一折算，年代之间本来就该不一样。）

5. [ ] **网页从头到尾玩得通** — 怎么验证：本机 `pm2` 起 `hundredyears`，浏览器打开
   `http://127.0.0.1:8801` 走完一局。`goal/shots/` 里有截图：选年选月、写清单（含超字数被挡住）、
   当天结果、翻年卡、30 天结算、年榜、总榜。手机宽度 390×844 再补一张不横向溢出的。
   无 JS 报错、无资源缺失。

6. [ ] **界面上写死的文案说人话** — 怎么验证：`node tools/renhua/check.js` 退出码 0
   （禁用词 0 命中，难读分不超过 4.5）。
   **模型实时生成的正文不做事后过滤，也不做离线抽样**——sway 定的「实时那些不管」，
   那一层的规矩写进 `sim.js` 的系统提示词里（规则 + 三句正面范例 + 三句反面范例）。

7. [ ] **上线** — 怎么验证：`https://100y.swaylab.ai` 打得开、能开一局、能提交一天。
   用 `expose-tunnel` skill 自己开（rathole 客户端配置是全机共用的，只许**追加**、改前先备份）。
   开完在 `TOOLS.md` 记一笔并告诉 asst。

# 不做什么

- 不做账号密码系统。排行榜用「昵称 + 浏览器里存的一串随机 token」认领成绩。
- 不做多人互动、不做实时对战、不做付费。
- 不做美术资源。界面只用字和排版。
- 不给模型实时生成的正文做事后把关（见第 6 条）。
